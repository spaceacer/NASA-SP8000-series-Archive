# NASA SP-8000 Series Archive

Complete NASA SP-8000 technical report archive with a Python/Google Colab
downloader for NTRS and legacy NASA reports.

## Complete PDF Archive

The complete collection of NASA SP-8000 reports is available as a
**~850 MB ZIP file** under [Releases].

Alternatively, use `NASA_8000_downloader.ipynb` to download and rebuild
the archive directly from the original sources.

Files are automatically named in the format:

`spXXXX_<document-ID>_<title>.pdf`

## Acknowledgements

Special thanks to **Richard Nakka** for maintaining the
[NASA SP-8000 Series index](https://www.nakka-rocketry.net/sp8000.html).

His index provided the starting point for locating the reports across
NASA NTRS and archived legacy NASA Technical Reports Server pages.
This project builds on that index by automating the retrieval, organization,
and consistent naming of the reports.
